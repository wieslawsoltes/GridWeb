# GridWeb.Blazor 0.1.0

First Blazor distribution of the real GridWeb workbook engine and virtualized editor, targeting .NET 8 and .NET 10.

- Spreadsheet and SpreadsheetInput components, revision-aware full JSON binding, selection/worksheet binding, EditContext integration and optional Razor command/formula toolbar.
- Typed workbook/range/worksheet APIs, atomic batches, calculation/history, pivots, tables, charts, formatting/validation, CSV/XLSX and print/SVG services.
- Shared/nonvisual workbook providers, native object/function access, streamed payloads, authenticated collaboration and self-contained worker assets.
- Pinned shared interop lifecycle/template runtime with deterministic teardown and no Dockyard/npm/CDN runtime dependency.
- WebAssembly and Interactive Server samples, actual-package consumer matrices, native/session regressions, publication verification, symbols and sample archives.

NuGet versioning is separate from npm and desktop adapter versions. Native GridWeb compatibility and security boundaries remain unchanged. Fonts are not distributed. Static-only SSR and synchronous Server callbacks do not become browser engines.
